# Frontend Static Site

A modern, ultra-fast static website built with a focus on web performance, accessibility, and clean architecture.

## 🚀 Key Features

*   **High Performance & SEO:** 100/100 Google Lighthouse scores achieved through Astro's Static Site Generation (SSG) compiler.
*   **Split-Navigation System (UX/UI Best Practice):** Completely independent, pixel-perfect navigation structures for desktop and mobile layouts to maximize responsiveness and thumb-zone usability.
*   **Advanced Mobile Overlay Menu:** Single-toggle accordion behavior with click-outside listener implemented in vanilla JavaScript.
*   **Unified Brand Identity:** Consistent layout and grid alignment driven entirely by global Tailwind utility classes and the Verdana font stack.
*   **DRY Architecture:** Highly scalable and reusable custom CSS components isolated in `global.css`.

## 🛠️ Tech Stack

*   **Framework:** Astro v4 (Static Site Generation)
*   **Styling:** Tailwind CSS v4
*   **Language:** TypeScript
*   **Design System Font:** Verdana / DejaVu Sans

## 📦 Getting Started

To run this project locally on your machine, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/maciej-browarski/frontend-static-site.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open `http://localhost:4321/` in your browser.
